# The Tired Dark Lord

A 100-word monologue spoken by a fantasy villain who conquered a kingdom with three words and a borrowed storm — and now has to live in it. The tiredness is never announced; it sits in the sighing step, the ledger, the heroes who arrive on Tuesdays, and the tea that is already poured. The last line turns the invitation into the trap: the hero came to be slain and will stay for tea instead.

The monologue is written to be spoken aloud in one breath, with short sentences a performer can land and a sting at the end.

`main.py` (Python standard library only) writes the monologue to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), then reads it back and verifies it byte-for-byte. The text is validated before writing: UTF-8, non-blank, at most 600 characters.

## Run it

```sh
python3 main.py
```
